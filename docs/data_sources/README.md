## Bounded acquisition utility

`scripts/acquire_data.py` currently downloads the NOAA feeds, NASA OSDR RR-1
mission dashboard, UCI MHEALTH and CELSS independently. It preserves raw
files, resumes partial transfers, verifies SHA-256, applies a total byte
budget and writes each result or failure to `data/manifests/acquisition.json`.
A failed URL is recorded without preventing other sources from being processed.

```bash
python3 scripts/acquire_data.py --source nasa_eda_rr_1 --source noaa_xray --source noaa_solar_wind --max-mb 8
python3 scripts/build_pivot.py
python3 scripts/import_pivot.py --dry-run
python3 scripts/import_pivot.py --api-url http://127.0.0.1:3080
python3 scripts/acquire_data.py --source uci_mhealth --max-mb 180
```

The checked NOAA conversion selected the GOES 0.05–0.4 nm band and active
RTSW rows, preserved source hashes and row locations, normalized timestamps
to UTC, and validated each record against `pivot.schema.json`. NASA EDA RR-1
provides ISS temperature, relative humidity and CO₂; its timestamps have no
explicit timezone in the dashboard, so records are retained as `suspect` and
excluded from rules and trends pending confirmation. Radiation series remain
unmapped because their units/period semantics were not verified; they are not
counted as imported radiation observations. Ground control values are not
mapped to ISS indicators. Missing sensor values are rejected rather than
imputed.
The output is `data/normalized/observations.jsonl`; it currently contains
47,767 schema-valid NASA/NOAA measurements from the acquired snapshots.

MIMIC-IV, Sleep-EDF, MIT-BIH and NASA OSDR BDAPI are not falsely reported as
acquired: they need dedicated, license-aware connector implementations. The
acquired CELSS supplementary archive contains only two image figures and
provides no machine-readable measurements, so no physiological observations
were generated from it. MHEALTH samples do not carry absolute timestamps;
mapping them to artificial calendar dates is intentionally avoided.

## Offline Knowledge Corpus

`data/corpus.jsonl` contains nine curated, paraphrased summaries from NASA HRP
and Canadian Space Agency pages. Entries preserve publisher, document title,
section, source URL, and a source-reported update date when available; the
date the summary was prepared is stored separately. NASA pages without a
visible update date do not get an invented document date. The CSA radiation
overview is dated 2006-08-18 and is included only for general context, not as a
current exposure-limit source. No source HTML/PDF is archived and there is no
automated refresh or source-version comparison yet; follow each citation URL
to verify current wording. Search responses identify these entries as
`curated_summary`, not verbatim source excerpts.
